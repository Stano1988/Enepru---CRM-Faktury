# Další vývoj

Výchozí zadání je zachované v docs/CONTINUE.md a aktuální implementace je rozlišená v docs/FEATURES.md. Základní průchod poptávka → nabídka → zakázka → faktura → úhrada → předání → archiv funguje; stále zbývají podrobnější rozšíření.

1. Opravné doklady, import externích faktur, více záloh, rozdělení bankovní platby.
2. PDF nabídky, odmítnutí/revokace, obchodní připomínky, další automatizace.
3. Sloučení duplicit, klientská historie, strukturovaná odborná data.
4. Hromadné dokumentové operace, náhled, skener příloh.
5. Uložené filtry, grafy, kapacitní plán a pokročilé finanční reporty.
6. Dokončení granulárních práv a testování všech rolí.
7. Skutečné SMTP, ověřený formát MONETA a další integrace s dostupným oprávněním.
8. Soukromé HTTPS nasazení a externí zálohování.

Účetní náležitosti a retenční lhůty potvrdit pro skutečný provoz. Publikace ani produkční připravenost nejsou doložené. Nepoužívat dosud neověřené funkce pro ostré klienty.
